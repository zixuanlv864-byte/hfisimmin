# How Far I Swimmin

这是可直接发布到 GitHub Pages 的版本。

上传到 GitHub 后，仓库首页必须直接看到 `index.html` 和 `README.md`，不能再套一层文件夹。

完整结构：

- `index.html`
- `.nojekyll`
- `.github/workflows/pages.yml`
- `README.md`

在 `Settings → Pages` 中将 `Source` 设为 `GitHub Actions`。上传完成后，打开 `Actions`，等待 `Deploy How Far I Swimmin` 出现绿色对勾。
